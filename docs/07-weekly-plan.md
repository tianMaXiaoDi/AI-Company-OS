# 周计划与复盘

## 标准周节奏

| 日 | 焦点 | 最小交付 |
| --- | --- | --- |
| 周一 | 选择本周成果，拆解任务和风险 | 1 个周目标、最多 5 张执行卡 |
| 周二 | 核心构建 | 可运行的第一个切片 |
| 周三 | 核心构建与评估 | 新增评估案例或真实样例 |
| 周四 | 集成、可靠性、文档 | 可演示端到端流程 |
| 周五 | 发布、用户反馈、职业资产 | Demo/文章/用户访谈至少一项 |
| 周六 | 技术债、学习、补缺 | 将学习转换为项目改进 |
| 周日 | 复盘与恢复 | 周报、下周草案；不强制重工作 |

## 每周固定问题

1. 本周唯一可展示的结果是什么？谁会关心它？
2. 哪个假设需要最早验证？
3. 证据显示 Agent 在哪里失败？应该改 Prompt、工具、数据，还是不要用 Agent？
4. 下周要停止什么？

完整格式见 [`templates/weekly-review.md`](../templates/weekly-review.md)。
