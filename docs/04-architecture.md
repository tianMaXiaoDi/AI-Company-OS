# AI Company OS 架构

```text
CEO（你：战略、资金、质量与最终审批）
│
├── 产品与项目层：需求、优先级、实验、里程碑
├── 交付层：Java Agent / Review Agent / 诊断 Agent / 客服 Agent
├── 增长层：内容 Agent / 求职 Agent / 线索与 CRM 工作流
├── 知识层：规范、案例、评估集、客户知识库
└── 运营层：任务、指标、日志、权限、成本、复盘
```

## 最小 Agent 合同

每个 Agent 都放在 `agents/<agent-id>/`，至少包含：

- `README.md`：职责、非职责、用户价值、版本状态。
- `contract.md`：输入、输出、工具、权限、失败处理与人工审批点。
- `evals/`：代表性案例、期望结果、评分方式。
- `changelog.md`：版本、变更理由、评估结果。

## 工作流分层

1. **确定性层：** 数据校验、权限、订单查询、规则、审计记录。
2. **推理层：** 分类、提取、总结、建议、生成草稿。
3. **审批层：** 金钱、生产数据、对外发布、客户承诺必须有人确认。

先将关键业务约束留在确定性层，再让 Agent 在受控范围内推理。
