# 愿景、范围与成功定义

## 项目使命

把「8 年 Java 后端经验 + AI 客服实践 + 海外发展意愿」转化为一套可证明、可出售、可扩展的个人 AI 公司能力。你是 CEO、产品负责人和最终责任人；AI 是一组有明确职责的数字员工，而不是替代判断的黑箱。

## 三条业务主线

| 主线 | 12 个月成果 | 优先客户/场景 |
| --- | --- | --- |
| AI 客服与业务自动化 | AI 客服 2.0 可演示、可部署、可试用 | 有订单、退款、知识库流程的小团队 |
| 工程生产力 | Java/Review/日志/数据库诊断工作流 | Java 后端团队与个人开发者 |
| 个人增长与全球机会 | 求职、内容、作品集自动化系统 | 自己；随后再验证同类用户 |

## 非目标

- 不追逐所有框架、模型和新闻。
- 不在没有真实流程前构建「万能 Agent」。
- 不为了 GitHub 提交数而做无效 Demo。
- 不把高风险操作（退款、删库、发正式邮件、支付）完全交给无审批 Agent。

## 成功指标

### 领先指标（每周）

- 4–6 次专注工作时段；1 个公开或可分享的增量。
- 1 次用户/同行/潜在雇主反馈触点。
- 1 次运行数据或评估记录，而非只凭主观感受。

### 结果指标（每月）

- 产品：试用用户数、激活率、每周活跃、付费/意向收入。
- 工程：端到端成功率、人工介入率、关键流程耗时、单次任务成本。
- 增长：高质量内容数、有效对话数、作品集访问或面试机会。
- 个人：完成里程碑数、连续复盘周数、可复用资产数。

## 决策优先级

真实用户价值 > 可维护性 > 可演示性 > 学习价值 > 新潮技术。
