# AI Customer Service Agent

## 问题

电商客户服务通常跨越订单、物流、退款政策和人工支持；把所有回答交给模型会造成编造事实、越权访问和高风险操作的问题。

## v0.2 用户价值

客户可在一个入口查询自己订单的物流状态，或将复杂问题升级为人工工单。系统保证订单事实来自业务工具，并拒绝跨客户查询。

## v0.2 成功标准

- 三条可复现链路：物流查询、越权拒绝、人工升级。
- 每条链路都有 `trace_id` 和工具执行结果，并追加写入 PostgreSQL 审计事件。
- 退款请求不会直接执行，明确进入人工审核边界。

## 非目标

- 不构建全功能客服 Portal。
- 不接入真实订单、支付或 CRM 系统。
- 不在没有经过评估和权限设计前引入自动退款。

## 下一阶段验收

已接入 Spring Boot + PostgreSQL，并保留 API 语义和授权测试。下一阶段将企业政策知识库接入受控的 RAG 检索，回答必须附带来源。
