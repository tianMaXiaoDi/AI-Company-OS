# 会话感知路由原则

## 目标

实时 Agent 任务在扩缩容和故障转移时，优先保持同一 `session_id` 的上下文连续性；上下文不在本地实例时，必须从持久化会话存储恢复，而不是静默地开启新会话。

## 路由顺序

1. 查找持有该 `session_id` 工作集的健康实例。
2. 若实例容量足够，优先复用并记录 affinity 命中。
3. 若实例不可用或过载，选择健康实例并从持久化状态恢复。
4. 恢复失败时停止继续执行，产生告警并请求人工处理；不得丢失上下文后继续执行高风险动作。

## 必须记录

路由原因、候选实例、最终实例、队列等待时间、上下文恢复耗时、affinity 命中/未命中、故障转移原因和结果。
